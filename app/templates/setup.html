01

Create a Meta developer app

Sign in using the Facebook account that manages your Page. Create an app/use case that supports Facebook Login and Page publishing. Copy the App ID and App Secret from its settings.

Open Meta apps dashboard ↗ · Meta developer resources ↗

02

Register the OAuth callback

Configure Facebook Login for Web. In its OAuth settings, register this exact callback URI when the dashboard asks for Valid OAuth Redirect URIs.

{{ redirect_uri }}
03

Make sure the app can publish to Pages

Partly requests these permissions during Facebook authorization:

  • pages_show_list — list Pages you manage
  • pages_read_engagement — Page context
  • pages_manage_posts — publish Reels

For Development mode testing, use an account added to the app as an administrator, developer, or tester. Public use may require Meta App Review and Advanced Access.

Read Meta's Reels API collection ↗

04

Save the app credentials locally

In the project folder, open .env in Notepad. If it doesn't exist, copy .env.example to .env. Fill in these values:

FACEBOOK_APP_ID=your_app_id_here
FACEBOOK_APP_SECRET=your_app_secret_here
FACEBOOK_REDIRECT_URI={{ redirect_uri }}
META_GRAPH_API_VERSION={{ graph_api_version }}

Replace both placeholders with your own values, save the file, and restart the server. Never commit the real .env file.

05

Connect and automate

  • Return to the home screen and click Connect Facebook.
  • Approve the requested permissions in Facebook's own authorization screen.
  • Select the Page you manage in the destination dropdown.
  • Upload a short video you own, wait for the numbered clips, then click Publish all clips in order.

Partly uploads clips sequentially and stops if a part fails, rather than skipping later clips silently.

Keep your App Secret private. Never paste it into ChatGPT or commit it to GitHub. The project excludes .env and local data/ files. Keep this app bound to localhost.
